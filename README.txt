راهنمای نصب برنامه پروژه یخچال هوشمند

۱) فایل ZIP را از حالت فشرده خارج کن.
۲) پوشه را روی یک سرویس میزبانی استاتیک با HTTPS منتشر کن (مثلاً GitHub Pages).
۳) نشانی HTTPS سایت را با Chrome در گوشی باز کن.
۴) اندروید: منوی سه‌نقطه Chrome > Install app یا Add to Home screen.
   آیفون: دکمه Share در Safari > Add to Home Screen.

نکته: نصب PWA از فایل محلی یا لینک sandbox به‌تنهایی ممکن نیست؛ برای نصب واقعی، سایت باید روی HTTPS میزبانی شود.
تیک‌ها در حافظه مرورگر همان گوشی ذخیره می‌شوند. این برنامه فقط زمان‌بندی و پیگیری کارهاست و هنوز به آردوینو/ESP8266 متصل نیست.
